StreamFix Source on GitHub

Valid JSON out of LLM output, even mid‑stream.

Models wrap JSON in fences, think out loud, write Python literals and get cut off. StreamFix edits that back into the JSON the model meant: on complete responses, on tool-call arguments, and live on a token stream.

Syntax repair is done by json-repair. StreamFix adds what surrounds it: reasoning- and fence-aware extraction, completing a cut-off tru or "key":, a streaming repairer, schema checks, and a proxy.

Use it as a library

pip install "streamfix @ git+https://github.com/rozetyp/streamfix"

from streamfix import repair
result = repair(model_output)
result.value     # the parsed JSON, or None
result.repairs   # what was fixed, e.g. ["fence_strip"]

For streams, feed each delta to StreamProcessor and send on what it returns. Commas and bare words are held only until the next token settles them, and a stream that stops early is closed into valid JSON.

Or run the proxy

pip install "streamfix[server] @ git+https://github.com/rozetyp/streamfix"
STREAMFIX_UPSTREAM_URL=https://openrouter.ai/api/v1 streamfix serve

client = OpenAI(base_url="http://localhost:8000/v1", api_key=YOUR_KEY)
client.chat.completions.create(model=..., messages=...,
    extra_body={"schema": SCHEMA})   # optional contract mode

It proxies chat completions, so existing OpenAI client code keeps working with a new base_url. Your key passes through to the upstream, and nothing is stored.

The public instance at https://streamfix.dev/v1 forwards to OpenRouter and has no key of its own, so send your OpenRouter key. If you'd rather not route requests through a third party, run your own copy; it's one command.

Limits

  • It recovers what the model meant to write, not what it never wrote. A cut-off answer comes back valid but incomplete.
  • Picking the answer out of several JSON values is a heuristic: one separated by prose is chosen, glued-together values follow json-repair's convention.
  • A stream can't take back a draft it already sent; the full repair at the end is the authoritative answer.
  • Schema retries happen once, and only without streaming.
